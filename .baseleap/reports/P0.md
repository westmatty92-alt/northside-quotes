## GHL tag convention (my pick, recorded as OQ-13A)
- Tags: `quote-new`, `quote-quoted`, `quote-won`, `quote-lost`. `quote-request` stays on every contact.
- The previous stage tag is removed in the same update, so a contact carries exactly one stage tag. A new contact is created with `quote-request` plus the stage tag for the request's status at that moment.
- The app never removes a tag it did not add and changes no other contact field.
- Outage rule is the same as default 8A: status saved first; waiting state, retried at least every 24 hours, up to 5 retries after the first attempt, then "Stage tag failed". Retries apply the current status, not an older one; a later change starts a new push. A missing or rejected token shows failed at once, as the copy does (AC-009.3). It never blocks, delays beyond 3 seconds or reverses the status change (AC-017.12).
